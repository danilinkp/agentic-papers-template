---
name: find-literature
description: Искать научные статьи, проверять DOI и метаданные, вести журнал поиска, извлекать подтверждения из первоисточников и готовить записи BibTeX для обзора литературы.
---

- Сформулируй запросы по понятиям исследовательского вопроса. Сохрани базы, запросы, даты и фильтры в research/sources.md. Выбери тематические базы по дисциплине и пригодности для вопроса.
- Используй academic_literature для Crossref и arXiv, если он доступен. Используй zotero_search и zotero_export_bibtex для библиотеки Zotero Desktop, когда доступен её локальный API. Google Scholar можно использовать для дополнительного поиска. При недоступности MCP воспользуйся поиском в сети, предметными каталогами или предоставленными текстами. Для значимого утверждения открой первоисточник. Для PDF извлекай текст через pdf_read_pages, а таблицы, формулы, сканы и порядок колонок проверяй через pdf_render_page.
- Сверь DOI с заглавием, авторами, годом и версией. Если DOI зарегистрирован в Crossref, используй verify_citation для проверки заглавия, фамилии первого автора и года. Сгруппируй препринт и опубликованную версию одной работы, укажи реально прочитанную версию. Отметь доступ только к аннотации. Проверь доступные уведомления об исправлении и отзыве на странице публикации, если источник существенен для вывода.
- Зафиксируй для каждого принятого источника утверждение и место в тексте. Если нужна библиография, добавляй проверенные записи в docs/bibliography.bib, сохраняя существующие ключи. Сверяй поля записей с форматом в README.md. Crossref, arXiv и Zotero помогают найти или описать источник. Доказательство тезиса извлекай из прочитанного материала.
